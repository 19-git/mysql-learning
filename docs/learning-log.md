## 2026-11-14

- 环境：MySQL + DataGrip，本机连接 127.0.0.1:3306
- 练习内容：
  - 员工表 `emp` 建表与初始数据插入
  - 基础查询：指定字段、全字段、别名、去重
  - 条件查询：`is null`、`!=`、`between and`、`and/or`、`in`、`like`
  - 聚合函数：`count`、`avg`、`max`、`min`、`sum`
  - 分组查询：`group by` + `having`
  - 分页查询：`limit`
  - 排序查询：`order by`
- 易错点：`where` 在分组前过滤原始数据，`having` 在分组后过滤聚合结果。
